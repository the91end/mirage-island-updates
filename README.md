# Mirage Island live updates

Published automatically by the Android workflow in the (private) game repo on every push to main.
The Android app reads `manifest.json` on startup and downloads the files that changed, by checksum,
from `files/`. Don't edit by hand: each publish replaces this repo's history with a single commit.
